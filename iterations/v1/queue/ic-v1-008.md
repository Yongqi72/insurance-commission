    example: Given 批次列表页点击"+ 新建批次"，When 填写"2026年8月批次"点击"创建"，Then 跳转批次详情路由且头部状态标签显示"进行中"
    golden: false
  - |-
    (源：PRD AC-05)

    golden: false

    golden: false

    golden: false
