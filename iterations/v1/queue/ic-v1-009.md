acceptance-criteria:
  - |-
    (源：PRD AC-02)
    intent: 用户在批次详情页点击状态标签，可在"进行中"/"已完成"间切换，切换不影响导入/删除导入等任何后续操作的可用性
    oracle: 点击 `#tag-batch-status` 调用 `PATCH /api/commission-batches/:id/status`（`status` 取反当前值 doing<->done）；成功后本地状态即时更新，且"导入 Excel"按钮、导入记录"删除"入口保持可点击（不因状态置灰/禁用）；请求失败 `ElMessage.error` 提示，状态不回退前保持原值
    example: Given 状态"进行中"，When 点击 `#tag-batch-status`，Then 状态变"已完成"，`#btn-open-import` 仍可点击
    golden: false
  - |-
    (源：PRD AC-03)
    intent: 用户点击"导入 Excel"打开弹窗，选择本地文件点击"开始导入"，弹窗内展示"成功 N 行，失败 M 行"及失败行清单（行号+原因）
    oracle: 提交 `POST /api/commission-batches/:id/imports`（multipart，字段 `file`），成功响应渲染 `successCount`/`failCount`/`failRows`（每条 `{row, reason}`）于 `#import-result`；文件无法解析/未找到「账单」sheet（错误码 1001）走 catch 分支 `ElMessage.error` 透传后端 `msg`，不写入结果区；用户关闭弹窗后触发导入记录列表刷新
    example: Given 弹窗内选择"7月账单.xlsx"点击 `#btn-start-import`，Then `#import-result` 显示"成功导入 139 行，失败 0 行"
    golden: false

    (源：PRD AC-03，技术)

    oracle: 组件挂载及每次成功导入/删除导入后调用 `GET /api/commission-batches/:id/imports` 重新拉取并渲染 `#table-import-list`（顺序取后端返回，后端已按 importedAt 倒序，前端不再排序）；接入 `DataStateWrapper` 四态
    golden: false
  - |-
    (源：PRD AC-04)
    intent: 用户在导入记录列表点击某次导入的"删除"，二次确认后该次导入产生的记录从批次消失
    oracle: 点击 `.btn-delete-import` 触发 `ElMessageBox.confirm`（`type: 'warning'`，文案含"此操作不可撤销"）二次确认，确认后调用 `DELETE /api/commission-batches/:id/imports/:importId`，成功后 `ElMessage.success` 提示并从导入记录列表移除该行，同时触发一个可被后续挂载组件监听的记录变更信号（见 context）；取消确认不发起请求
    example: Given 某次导入成功导入 50 行，When 点击"删除"并在确认弹窗点击"确定删除"，Then 该次导入从 `#table-import-list` 消失
    golden: false
