# 保单提成管理系统用户操作说明

**适用对象：** 保单管理人员  
**适用版本：** V1

本系统以“创建批次 → 导入账单 → 回填销售人员 → 配置规则 → 核对并导出”的方式，完成保单提成统计。系统中的提成汇总为实时计算结果，请在导出前确认当前的销售人员信息和阶梯规则均已正确。

## 1. 开始前准备

### 1.1 登录

打开系统地址后输入管理员账号和密码，登录成功后默认进入“提成批次”页面。顶部导航可在“提成批次”和“提成阶梯规则”之间切换。

### 1.2 准备账单 Excel

每次导入的文件应满足以下要求：

- 文件格式为 `.xlsx` 或 `.xls`，且未损坏、未加密。
- 必须包含名称完全为“账单”的工作表。
- 第一行为表头；数据列顺序固定为：客户名称、工作单号、业务类型、币种、投保人、保险金额、保费、保单号。
- 客户名称、工作单号、业务类型、币种、投保人、保险金额、保单号不能为空；保险金额必须是数字。
- 保费可以留空；如填写，必须是数字。

同一个批次可分多次导入多个账单文件。工作单号或保单号重复不会阻止导入，请在导入前自行确认源文件是否重复。

## 2. 建议操作流程

1. 先在“提成阶梯规则”中确认规则完整可用。
2. 在“提成批次”中新建当期批次，并导入收到的全部账单。
3. 对批次执行“开始回填”，再筛选“未匹配”记录逐条人工补录。
4. 查看实时提成汇总，处理未匹配或异常记录。
5. 导出 Excel 报表，并在“导出历史”中留存和重新下载。
6. 业务处理结束后，可将批次状态标记为“已完成”。该状态仅用于标记，不会锁定后续操作。

## 3. 创建和管理提成批次

### 新建批次

1. 在顶部导航进入“提成批次”。
2. 点击“+ 新建批次”。
3. 填写批次名称并提交。

系统会进入该批次详情页，初始状态为“进行中”。批次名称允许重复，建议使用“年月 + 业务范围”等便于识别的名称，例如“2026年9月华东批次”。

### 查看与切换状态

- 批次列表按创建时间倒序排列，点击批次可进入详情页。
- 在详情页顶部点击状态标签，可在“进行中”和“已完成”之间切换。
- 即使状态为“已完成”，仍可继续导入、删除导入、回填、补录和导出；请以实际核对结果决定是否操作。

系统不支持删除整个批次。

## 4. 导入账单 Excel

1. 进入目标批次详情页，在“导入记录”区域点击“导入 Excel”。
2. 点击“点击选择 Excel 文件”，选中本地账单文件。
3. 确认文件名后点击“开始导入”。
4. 查看导入结果中的成功行数、失败行数及失败行原因。

导入成功后，文件会出现在“导入记录”列表中。点击文件名可下载当时上传的原始文件；点击“失败”列中的数字可再次查看该次导入的失败原因。

### 导入失败的常见原因

| 现象 | 处理建议 |
| --- | --- |
| 提示“文件无法解析” | 确认文件可正常打开，且不是加密文件或非 Excel 文件。 |
| 提示“未找到「账单」sheet” | 将需要导入的工作表名称改为“账单”后重新上传。 |
| 个别数据行失败 | 根据提示补齐必填字段，或将保险金额/保费改为有效数字后重新导入。 |
| 保费为空 | 可以正常导入，无须补零。 |

### 删除某次导入

在导入记录对应行点击“删除”，阅读确认提示后选择“确定删除”。系统会删除该次导入产生的全部保单记录；原始上传文件仍会保留在存档中供追溯。

> 此操作不可撤销。系统不支持删除单条保单记录；如需撤销，只能删除整次导入后修正文件并重新导入。

## 5. 回填和维护销售人员

### 批量回填

1. 在“保单记录明细”区域点击“开始回填”。
2. 等待进度窗口完成，并查看结果提示。

系统仅尝试处理当前仍为“未匹配”的记录，不会覆盖已由系统回填或人工补录的销售人员。若未获得销售人员信息，记录会保留为“未匹配”；这不是导入失败，需要后续人工处理。

### 筛选、搜索与人工补录

1. 使用“回填状态”下拉框筛选“未匹配”，集中处理待补录记录。
2. 也可在搜索框按工作单号、保单号或客户名称查找记录。
3. 点击需要处理的保单记录行，展开编辑区。
4. 在“销售人员”中填写或修改姓名，点击“保存”。

保存后，该记录会标识为“人工补录”，并自动计入实时提成汇总。系统会保留每一次人工修改，已补录的销售人员也允许再次修改。

### 更正工作单号

展开保单记录后，可修改“工作单号”并保存。若该记录已有销售人员回填结果，可按需要勾选“同时清空原销售人员回填结果”：

- 不勾选：仅更正工作单号，保留现有销售人员信息。
- 勾选：更正工作单号的同时清空销售人员信息，记录将重新成为“未匹配”，应再次回填或人工补录。

### 查看修改历史

在展开区点击“查看修改历史”，可查看销售人员补录和工作单号修改的操作人、操作时间及修改前后值。历史记录仅供查看，不能编辑或删除。

## 6. 配置提成阶梯规则

从顶部导航进入“提成阶梯规则”。全系统只维护一套统一规则，任何改动会立即影响各批次的实时汇总和之后新导出的报表。

### 新增或编辑档位

1. 点击“+ 新增档位”，或在已有档位后点击“编辑”。
2. 填写下限、上限和单价（元/票），然后保存。

区间采用“下限开区间、上限闭区间”的口径：`(0, 50]` 代表 1 至 50 票。单价必须大于 0；最高档的上限可留空，表示“及以上”。

系统会阻止与已有档位重叠的区间，但允许档位之间暂时存在空隙。要使规则可用于计算，须同时满足：

- 第一档下限为 0；
- 相邻档位首尾相接、没有空隙；
- 最后一档上限为空，覆盖到无穷大。

例如：`(0,50]`、`(50,100]`、`(100,及以上)` 为一套完整规则。若页面显示“规则不完整（存在空隙），提成计算暂不可用”，请补齐或调整档位后再导出。

### 删除与查看历史

- 点击档位后的“删除”，确认后即可删除。删除后请检查相邻档位是否形成空隙。
- 点击“查看变更历史”，可查看每次新增、编辑、删除的操作人、时间和变更内容。

规则历史不能一键回滚；如需恢复旧规则，请手动新增或编辑为目标值，系统会新增一条变更记录。

## 7. 核对实时提成汇总

批次详情页底部的“提成汇总（实时）”会按投保人分组显示：每位销售人员的票数、提成单价、提成金额，以及该投保人的合计金额。

- 票数按**同一投保人内**的销售人员记录计算，不会跨投保人合并定档。
- 提成金额 = 该投保人内的销售票数 × 对应阶梯单价。
- “未匹配”记录会显示票数，但不计入任何销售人员的提成，也不会阻止导出。
- 页面显示“未配置规则，无法计算”时，请先完成阶梯规则配置。

汇总会随导入、删除导入、销售人员补录或规则修改而刷新。请以导出前页面显示的最新数据为准。

## 8. 导出与重新下载报表

### 导出 Excel

确认汇总无误后，在“提成汇总（实时）”区域点击“导出 Excel”。浏览器会下载 `.xlsx` 报表，并新增一条导出历史记录。

报表按投保人分工作表；每个工作表包含：

- 上方：该投保人下的全部保单明细；未匹配记录的销售列留空。
- 下方：销售汇总（销售姓名、票数、提成单价、提成）及提成合计。

若某投保人下没有已确认销售人员，明细仍会导出，但销售汇总为空，合计为 0。

### 导出历史

点击“导出历史”打开右侧抽屉，可按时间查看该批次过去导出的报表。点击“重新下载”可下载当时已归档的文件，不会重新计算报表。

> 汇总页面和每一次新导出均使用当时的实时数据；已归档的历史文件则保留其导出时的内容。规则或补录发生变化后，如需反映新口径，请重新导出一份新报表。

## 9. 使用限制与注意事项

- 系统为单一管理员使用，不区分角色权限。
- 暂不支持批量人工补录；请逐条处理销售人员。
- 暂不支持删除批次、删除单条保单记录或删除修改历史。
- 投保人名称按账单原值分组和分 sheet，不会自动合并名称相近的分站或投保人。
- 仅支持导出 Excel，不支持 PDF 或 CSV。

如遇到无法判断的导入失败、回填异常或计算结果异常，请保留批次名称、导入文件名、失败行提示和操作时间，交由系统管理员排查。
